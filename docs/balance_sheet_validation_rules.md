# 资产负债表勾稽校验规则

## 基础合计公式

### 1. 流动资产合计

```text
流动资产合计
= 货币资金
+ 交易性金融资产
+ 衍生金融资产
+ 应收票据
+ 应收账款
+ 应收款项融资
+ 预付款项
+ 其他应收款
+ 存货
+ 合同资产
+ 持有待售资产
+ 一年内到期的非流动资产
+ 其他流动资产
```

### 2. 其他应收款

```text
其他应收款 = 应收利息 + 应收股利
```

备注：仅当 `应收利息` 或 `应收股利` 存在时触发。

### 3. 非流动资产合计

```text
非流动资产合计
= 债权投资
+ 其他债权投资
+ 长期应收款
+ 长期股权投资
+ 其他权益工具投资
+ 其他非流动金融资产
+ 投资性房地产
+ 固定资产
+ 在建工程
+ 生产性生物资产
+ 油气资产
+ 使用权资产
+ 无形资产
+ 开发支出
+ 商誉
+ 长期待摊费用
+ 递延所得税资产
+ 其他非流动资产
```

### 4. 流动负债合计

```text
流动负债合计
= 短期借款
+ 交易性金融负债
+ 衍生金融负债
+ 应付票据
+ 应付账款
+ 预收款项
+ 合同负债
+ 应付职工薪酬
+ 应交税费
+ 其他应付款
+ 持有待售负债
+ 一年内到期的非流动负债
+ 其他流动负债
```

### 5. 其他应付款

```text
其他应付款 = 应付利息 + 应付股利
```

备注：仅当 `应付利息` 或 `应付股利` 存在时触发。

### 6. 非流动负债合计

```text
非流动负债合计
= 长期借款
+ 应付债券
+ 租赁负债
+ 长期应付款
+ 预计负债
+ 递延收益
+ 递延所得税负债
+ 其他非流动负债
```

### 7. 所有者权益（或股东权益）合计

```text
所有者权益（或股东权益）合计
= 实收资本（股本）
+ 其他权益工具
+ 资本公积
- 库存股
+ 其他综合收益
+ 专项存储
+ 盈余公积
+ 未分配利润
```

备注：当出现 `归属于母公司所有者权益（或股东权益）合计` 或 `少数股东权益` 时跳过该单体口径规则。

### 8. 其他权益工具

```text
其他权益工具 = 所有者权益优先股 + 所有者权益永续债
```

备注：仅当 `所有者权益优先股` 或 `所有者权益永续债` 存在时触发。

### 9. 归属于母公司所有者权益（或股东权益）合计

```text
归属于母公司所有者权益（或股东权益）合计
= 实收资本
+ 其他权益工具
+ 资本公积
- 库存股
+ 其他综合收益
+ 专项储备
+ 盈余公积
+ 未分配利润
```

备注：仅当出现 `归属于母公司所有者权益（或股东权益）合计` 或 `少数股东权益` 时触发。

### 10. 所有者权益合并口径

```text
所有者权益（或股东权益）合计
= 归属于母公司所有者权益（或股东权益）合计
+ 少数股东权益
```

备注：仅当出现 `归属于母公司所有者权益（或股东权益）合计` 或 `少数股东权益` 时触发；`少数股东权益` 缺失时可按 `0` 参与校验。

## 层级平衡公式

### 11. 资产总计

```text
资产总计 = 流动资产合计 + 非流动资产合计
```

### 12. 负债合计

```text
负债合计 = 流动负债合计 + 非流动负债合计
```

### 13. 负债和所有者权益总计：按负债小计展开

```text
负债和所有者权益（或股东权益）总计
= 流动负债合计
+ 非流动负债合计
+ 所有者权益（或股东权益）合计
```

### 14. 负债和所有者权益总计：按负债合计展开

```text
负债和所有者权益（或股东权益）总计
= 负债合计
+ 所有者权益（或股东权益）合计
```

### 15. 资产负债表平衡

```text
负债和所有者权益（或股东权益）总计 = 资产总计
```

等价表达：

```text
资产总计 = 负债和所有者权益（或股东权益）总计
```

## 资产负债表整体校验与归因入口

本节是整张资产负债表勾稽校验的入口树。入口先判断左右两侧顶层总计是否平衡，再分别调用资产侧、负债权益侧和负债侧的下级子树。下级子树负责把问题继续落到具体科目，例如 `流动资产合计: 字段缺失`、`非流动负债合计: 疑似字段错误`。

整体归因使用三个候选值：

```text
资产侧候选值 = 流动资产合计候选值 + 非流动资产合计候选值

负债侧候选值 = 流动负债合计候选值 + 非流动负债合计候选值

负债权益侧候选值
= 负债合计候选值 + 所有者权益（或股东权益）合计候选值
```

候选值形成规则：

- 合计披露值自身校验通过时，优先使用披露值。
- 合计披露值缺失或自身校验失败时，使用对应子树已经被上层验证的重算值或反推值。
- 如果既没有披露值，也没有被验证的重算值或反推值，则该候选值不可用。

### 最终平衡公式决策树

本树专门处理最终平衡公式：

```text
资产总计 = 负债和所有者权益（或股东权益）总计
```

先形成两个参与最终平衡校验的值：

```text
资产总计参与值
= 资产总计披露值
  或 资产总计缺失时的资产侧候选值

负债权益总计参与值
= 负债和所有者权益（或股东权益）总计披露值
  或 负债和所有者权益（或股东权益）总计缺失时的负债权益侧候选值
```

叶子节点输出采用 `科目: 提示语`。提示语沿用现有短原因：`字段缺失`、`字段缺失，推测值是{金额}`、`疑似字段错误`、`疑似字段错误，推测值是{金额}`、`无法校验`、`校验未通过`、`子项和不匹配`、`校验通过`。只有被左右两侧共同验证过的推导值才进入 `推测值是{金额}`。

```text
资产总计 = 负债和所有者权益（或股东权益）总计 校验
├─ 资产总计参与值能否形成？
│  ├─ 否
│  │  ├─ 资产总计是否有披露值？
│  │  │  ├─ 有值 -> 输出：资产总计: 无法校验；进入资产侧结构子树
│  │  │  └─ 无值 -> 输出：资产总计: 字段缺失；进入资产侧结构子树
│  └─ 是
│     ├─ 负债权益总计参与值能否形成？
│     │  ├─ 否
│     │  │  ├─ 负债和所有者权益（或股东权益）总计是否有披露值？
│     │  │  │  ├─ 有值 -> 输出：负债和所有者权益（或股东权益）总计: 无法校验；进入负债权益侧结构子树
│     │  │  │  └─ 无值 -> 输出：负债和所有者权益（或股东权益）总计: 字段缺失；进入负债权益侧结构子树
│     │  └─ 是
│     │     ├─ 资产总计参与值 = 负债权益总计参与值？
│     │     │  ├─ 是
│     │     │  │  ├─ 资产总计是否缺失？
│     │     │  │  │  ├─ 是 -> 输出：资产总计: 字段缺失，推测值是{资产总计参与值}
│     │     │  │  │  └─ 否 -> 输出：资产总计: 校验通过
│     │     │  │  ├─ 负债和所有者权益（或股东权益）总计是否缺失？
│     │     │  │  │  ├─ 是 -> 输出：负债和所有者权益（或股东权益）总计: 字段缺失，推测值是{负债权益总计参与值}
│     │     │  │  │  └─ 否 -> 输出：负债和所有者权益（或股东权益）总计: 校验通过
│     │     │  │  └─ 继续检查资产侧结构子树和负债权益侧结构子树
│     │     │  └─ 否
│     │     │     └─ 进入顶层不平衡归因分支
```

顶层不平衡时，同时检查左右两侧是否能解释自己的顶层总计：

```text
顶层不平衡归因分支
├─ 资产侧结构是否支持资产总计披露值？
│  ├─ 是
│  │  ├─ 负债权益侧结构是否支持负债权益总计披露值？
│  │  │  ├─ 是
│  │  │  │  └─ 输出：资产总计: 校验未通过；负债和所有者权益（或股东权益）总计: 校验未通过
│  │  │  └─ 否
│  │  │     ├─ 资产侧候选值 = 负债权益侧候选值？
│  │  │     │  ├─ 是 -> 输出：负债和所有者权益（或股东权益）总计: 疑似字段错误，推测值是{负债权益侧候选值}
│  │  │     │  └─ 否 -> 输出：负债和所有者权益（或股东权益）总计: 校验未通过；进入负债权益侧结构子树
│  └─ 否
│     ├─ 负债权益侧结构是否支持负债权益总计披露值？
│     │  ├─ 是
│     │  │  ├─ 资产侧候选值 = 负债权益侧候选值？
│     │  │  │  ├─ 是 -> 输出：资产总计: 疑似字段错误，推测值是{资产侧候选值}
│     │  │  │  └─ 否 -> 输出：资产总计: 校验未通过；进入资产侧结构子树
│     │  └─ 否
│     │     ├─ 资产侧候选值和负债权益侧候选值是否都能形成？
│     │     │  ├─ 是
│     │     │  │  ├─ 资产侧候选值 = 负债权益侧候选值？
│     │     │  │  │  ├─ 是 -> 输出：资产总计: 疑似字段错误，推测值是{资产侧候选值}；负债和所有者权益（或股东权益）总计: 疑似字段错误，推测值是{负债权益侧候选值}
│     │     │  │  │  └─ 否 -> 输出：资产总计: 校验未通过；负债和所有者权益（或股东权益）总计: 校验未通过；分别进入左右两侧结构子树
│     │     │  └─ 否 -> 输出：资产总计: 校验未通过；负债和所有者权益（或股东权益）总计: 校验未通过；分别进入左右两侧结构子树
```

备注：

- `资产侧结构是否支持资产总计披露值` 指 `资产总计披露值 = 资产侧候选值`。
- `负债权益侧结构是否支持负债权益总计披露值` 指 `负债和所有者权益（或股东权益）总计披露值 = 负债权益侧候选值`。
- 当左右两侧结构都支持各自披露值，但两边总计不相等时，说明两边各自内部自洽但整表不平衡，不能仅凭资产负债表内部公式单点判断哪一边错误。

### 资产侧结构子树

资产侧结构用于判断 `资产总计` 是否能被资产侧下级解释。

```text
资产侧结构是否自洽？
├─ 资产侧候选值能否形成？
│  ├─ 否 -> 输出：资产总计: 无法校验；进入流动资产合计/非流动资产合计子树
│  └─ 是
│     ├─ 资产总计是否有披露值？
│     │  ├─ 无值 -> 输出：资产总计: 字段缺失，推测值是{资产侧候选值}
│     │  └─ 有值
│     │     ├─ 资产总计 = 资产侧候选值？
│     │     │  ├─ 是 -> 输出：资产总计: 校验通过；继续检查流动资产合计/非流动资产合计子树
│     │     │  └─ 否 -> 进入「资产总计错误归因」
```

资产侧结构的下级子树：

```text
资产总计
├─ 流动资产合计
│  └─ 流动资产子项
└─ 非流动资产合计
   └─ 非流动资产子项
```

### 负债权益侧结构子树

负债权益侧结构用于判断 `负债和所有者权益（或股东权益）总计` 是否能被右侧下级解释。

```text
负债权益侧结构是否自洽？
├─ 负债权益侧候选值能否形成？
```

## 流动资产合计错误归因

本节只定义 `流动资产合计` 自身校验失败后的归因。核心判断不是只看 `流动资产合计` 是否等于子项之和，而是继续向上使用 `资产总计 = 流动资产合计 + 非流动资产合计` 做交叉验证。

```text
│     │     │     │     │  ├─ 是 -> 输出：流动资产合计: 字段缺失，推测值是{流动资产合计重算值}；非流动资产合计: 字段缺失，推测值是{非流动资产合计重算值}
│     │     │     │     │  └─ 否 -> 输出：流动资产合计: 字段缺失；非流动资产合计: 字段缺失
```

`流动资产合计是否通过自身校验` 为“是”时，`流动资产合计披露值` 可以作为可信辅助输入。为“否”时，必须继续区分 `流动资产合计` 是否有披露值，并用流动资产子项形成 `流动资产合计重算值` 参与交叉验证。

### 非流动资产差额反推分支

当 `非流动资产合计` 缺失，且 `流动资产合计披露值 + 非流动资产合计重算值 != 资产总计` 时，不能只写“非流动资产合计缺失”。此时应继续计算：

```text
非流动资产合计反推值 = 资产总计 - 流动资产合计披露值
非流动资产子项差额 = 非流动资产合计反推值 - 非流动资产合计重算值
```

| 判断 | 归因结论 |
| --- | --- |
| 存在明确候选子项证据，且候选子项金额或修正差额与 `非流动资产子项差额` 一致 | `非流动资产合计` 缺失，同时该子项缺漏或错误 |
| `非流动资产子项差额` 不能对应单个子项 | `非流动资产合计` 缺失，同时非流动资产子项存在多项缺漏或错误，无法单点定位 |

明确候选子项证据可以来自：

- 原始表格中出现但映射结果缺失的非流动资产子项，且其金额等于差额。
- 旧准则隐藏小计能解释差额，例如 `长期投资`、`固定资产合计`、`无形资产及其他资产合计`。
- 固定资产内部公式能解释差额，例如 `固定资产净额 = 固定资产净值 - 固定资产减值准备`。
- semantic/canonical 原始科目中存在该子项金额，且 view 层缺失。
- 只有一个非流动资产子项处于缺失、异常或低置信状态，且它能解释全部差额。

如果没有这些证据，差额只能证明“非流动资产子项侧仍不闭合”，不能凭差额本身单点定位到某个子项。

这条分支下，`资产总计` 和 `流动资产合计` 仍然是可信输入；问题范围应限制在 `非流动资产合计缺失` 和 `非流动资产子项` 内。

## 资产总计错误归因

```text
资产总计 = 负债和所有者权益（或股东权益）总计
```

1. 优先使用 `流动资产合计披露值 + 非流动资产合计披露值`。

## 非流动负债合计错误归因

本节定义 `非流动负债合计` 自身校验失败后的归因。核心判断与流动负债侧一致：先判断 `负债合计` 是否可信，再使用 `负债合计 = 流动负债合计 + 非流动负债合计` 做上层交叉验证。此时 `非流动负债合计` 是目标错误侧，`流动负债合计` 是辅助验证侧。

归因时会同时比较以下候选公式：


```text

```

## 归属于母公司所有者权益（或股东权益）合计错误归因

## 所有者权益（或股东权益）合计错误归因

本节定义 `所有者权益（或股东权益）合计` 自身校验失败后的归因。该科目存在两种口径：

- 单体口径：未出现 `归属于母公司所有者权益（或股东权益）合计` 和 `少数股东权益` 时，按权益明细子项求和。
- 合并口径：出现 `归属于母公司所有者权益（或股东权益）合计` 或 `少数股东权益` 时，按 `归属于母公司所有者权益（或股东权益）合计 + 少数股东权益` 求和。

权益候选值按口径形成：

```text
单体权益候选值
= 实收资本（股本）
+ 其他权益工具
+ 资本公积
- 库存股
+ 其他综合收益
+ 专项存储
+ 盈余公积
+ 未分配利润
```

```text
合并权益候选值
= 归属于母公司所有者权益（或股东权益）合计候选值
+ 少数股东权益
```

当 `负债和所有者权益（或股东权益）总计` 和 `负债合计` 都可信时，可以反推出所有者权益合计应有值：

```text
所有者权益（或股东权益）合计反推值
= 负债和所有者权益（或股东权益）总计
- 负债合计
```

### 主决策树

叶子节点输出采用 `科目: 提示语`。提示语沿用现有短原因：`字段缺失`、`字段缺失，推测值是{金额}`、`疑似字段错误`、`疑似字段错误，推测值是{金额}`、`无法校验`、`校验未通过`、`子项和不匹配`。只有被右侧总计或权益候选值验证过的推导值才进入 `推测值是{金额}`。

```text
所有者权益（或股东权益）合计校验错误
├─ 是否为合并口径？
│  ├─ 是
│  │  ├─ 合并权益候选值能否形成？
│  │  │  ├─ 否 -> 输出：所有者权益（或股东权益）合计: 无法校验；进入归母权益合计/少数股东权益子树
│  │  │  └─ 是 -> 进入权益合计通用归因分支，权益候选值 = 合并权益候选值
│  └─ 否
│     ├─ 单体权益候选值能否形成？
│     │  ├─ 否 -> 输出：所有者权益（或股东权益）合计: 无法校验
│     │  └─ 是 -> 进入权益合计通用归因分支，权益候选值 = 单体权益候选值
```

```text

├─ 所有者权益（或股东权益）合计是否有披露值？
│  ├─ 无值
│  │  ├─ 所有者权益合计反推值能否形成？
│  │  │  ├─ 是
│  │  │  │  ├─ 权益候选值 = 所有者权益合计反推值？

│  │  │  │  │  └─ 否 -> 输出：所有者权益（或股东权益）合计: 字段缺失；权益下级科目: 校验未通过
│  │  │  └─ 否 -> 输出：所有者权益（或股东权益）合计: 字段缺失，推测值是{权益候选值}
│  └─ 有值
│     ├─ 所有者权益（或股东权益）合计披露值 = 权益候选值？
│     │  ├─ 是
│     │  │  ├─ 所有者权益合计反推值能否形成？
│     │  │  │  ├─ 是
│     │  │  │  │  ├─ 所有者权益（或股东权益）合计披露值 = 所有者权益合计反推值？
│     │  │  │  │  │  ├─ 是 -> 输出：所有者权益（或股东权益）合计: 校验通过
│     │  │  │  │  │  └─ 否 -> 输出：负债和所有者权益（或股东权益）总计或负债合计: 校验未通过
│     │  │  │  └─ 否 -> 输出：所有者权益（或股东权益）合计: 校验通过
│     │  └─ 否
│     │     ├─ 所有者权益合计反推值能否形成？
│     │     │  ├─ 是
│     │     │  │  ├─ 所有者权益（或股东权益）合计披露值 = 所有者权益合计反推值？
│     │     │  │  │  ├─ 是 -> 输出：所有者权益（或股东权益）合计: 子项和不匹配
│     │     │  │  │  └─ 否
│     │     │  │  │     ├─ 权益候选值 = 所有者权益合计反推值？
│     │     │  │  │     │  ├─ 是 -> 输出：所有者权益（或股东权益）合计: 疑似字段错误，推测值是{权益候选值}
│     │     │  │  │     │  └─ 否 -> 输出：所有者权益（或股东权益）合计: 校验未通过

│     │     │     ├─ 权益下级科目是否均通过自身校验？

│     │     │     │  └─ 否 -> 输出：所有者权益（或股东权益）合计: 校验未通过；权益下级科目: 校验未通过
```

备注：

- 单体口径下，`权益下级科目` 指参与单体权益合计的明细子项。
- 合并口径下，`权益下级科目` 指 `归属于母公司所有者权益（或股东权益）合计` 和 `少数股东权益`。
- 若 `少数股东权益` 缺失但报表没有少数股东权益口径证据，可按 `0` 形成候选值；只有需要对外提示缺失时才输出 `少数股东权益: 字段缺失，推测值是0`。

## 负债和所有者权益（或股东权益）总计错误归因

本节定义 `负债和所有者权益（或股东权益）总计` 自身校验失败后的归因。核心判断是同时使用右侧下级合计和资产总计做交叉验证。

右侧候选值按以下公式形成：

```text
负债权益侧候选值
= 负债合计候选值
+ 所有者权益（或股东权益）合计候选值
```

也可以在 `负债合计` 缺失或不可用时使用展开口径：

```text
负债权益侧展开候选值
= 流动负债合计候选值
+ 非流动负债合计候选值
+ 所有者权益（或股东权益）合计候选值
```

### 主决策树

叶子节点输出采用 `科目: 提示语`。提示语沿用现有短原因：`字段缺失`、`字段缺失，推测值是{金额}`、`疑似字段错误`、`疑似字段错误，推测值是{金额}`、`无法校验`、`校验未通过`、`子项和不匹配`。只有被右侧候选值或资产总计验证过的推导值才进入 `推测值是{金额}`。

```text

├─ 负债权益侧候选值能否形成？
│  ├─ 否
│  │  ├─ 负债权益侧展开候选值能否形成？
│  │  │  ├─ 是 -> 使用负债权益侧展开候选值作为右侧候选值
│  │  │  └─ 否
│  │  │     ├─ 负债和所有者权益（或股东权益）总计是否有披露值？
│  │  │     │  ├─ 有值 -> 输出：负债和所有者权益（或股东权益）总计: 无法校验
│  │  │     │  └─ 无值 -> 输出：负债和所有者权益（或股东权益）总计: 字段缺失
│  └─ 是
│     ├─ 负债和所有者权益（或股东权益）总计是否有披露值？

│     │  │  ├─ 资产总计是否可信？
│     │  │  │  ├─ 是
│     │  │  │  │  ├─ 右侧候选值 = 资产总计？
│     │  │  │  │  │  ├─ 是 -> 输出：负债和所有者权益（或股东权益）总计: 字段缺失，推测值是{右侧候选值}
│     │  │  │  │  │  └─ 否 -> 输出：负债和所有者权益（或股东权益）总计: 字段缺失；右侧下级合计: 校验未通过
│     │  │  │  └─ 否 -> 输出：负债和所有者权益（或股东权益）总计: 字段缺失，推测值是{右侧候选值}
│     │  └─ 有值
│     │     ├─ 负债和所有者权益（或股东权益）总计披露值 = 右侧候选值？
│     │     │  ├─ 是
│     │     │  │  ├─ 资产总计是否可信？
│     │     │  │  │  ├─ 是
│     │     │  │  │  │  ├─ 负债和所有者权益（或股东权益）总计披露值 = 资产总计？
│     │     │  │  │  │  │  ├─ 是 -> 输出：负债和所有者权益（或股东权益）总计: 校验通过

│     │     │     ├─ 资产总计是否可信？
│     │     │     │  ├─ 是

│     │     │     │  │  │     │  ├─ 是 -> 输出：负债和所有者权益（或股东权益）总计: 疑似字段错误，推测值是{右侧候选值}
│     │     │     │  │  │     │  └─ 否 -> 输出：负债和所有者权益（或股东权益）总计: 校验未通过
│     │     │     │  └─ 否
```

- `右侧下级合计` 指 `负债合计` 和 `所有者权益（或股东权益）合计`；展开口径下还包括 `流动负债合计`、`非流动负债合计`。

## 辅助推导规则

以下规则不是独立展示的主校验项，主要用于在基础合计失败、缺失或旧准则口径下辅助定位问题。

### 非流动资产旧准则隐藏小计

```text
长期投资
= 长期股权投资
+ 其他权益工具投资
+ 债权投资
+ 其他债权投资
+ 其他非流动金融资产
```

旧准则兼容口径：

```text
长期投资 = 长期股权投资 + 长期债权投资
```

```text
固定资产合计 = 固定资产 + 工程物资 + 在建工程 + 固定资产清理
```

```text
无形资产及其他资产合计
= 无形资产
+ 长期待摊费用
+ 其他长期资产
+ 投资性房地产
```

### 固定资产内部推导

```text
固定资产净值 = 固定资产原价 - 累计折旧
```

```text
固定资产净额 = 固定资产净值 - 固定资产减值准备
```

该推导当前用于辅助判断 `固定资产` 参与 `非流动资产合计` 时是否存在字段金额错误。
