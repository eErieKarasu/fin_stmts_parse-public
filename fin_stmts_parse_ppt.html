Page 1 / 项目综述
项目目标 · 项目价值 · 当前实现

项目目标与定位

  • 建设一套财务报表结构化能力，将 PDF、图片、Excel 等非结构化财报资料自动转成标准化、可校验、可入库的财务数据。
  • 项目不是单纯做 OCR，而是在做“识别、标准化、校验、输出”一体化的数据生产链路。

项目价值

  • 减少人工录入和人工复核工作量，提升财报采集效率，缩短处理周期，降低重复劳动成本。
  • 把不同企业、不同模板、不同格式的财报数据统一到标准口径，为入库、分析、审核和智能化应用提供统一数据底座。
  • 将依赖人工经验的处理流程沉淀成可复用、可服务化的能力，便于后续横向扩展和系统接入。

  • 已支持 PDF、图片、Excel 三类文件统一接入，覆盖现阶段大部分财报资料来源。
  • 已实现财务三表自动识别，仅抽取资产负债表、利润表、现金流量表，避免整份文件无差别处理。
  • 已实现页面纠偏、方向识别、去水印、去印章，提升扫描件、截图件等低质量文件的识别稳定性。
  • 已完成表格抽取、标准科目映射、三表勾稽校验，输出结果具备业务可用性。
  • 已支持 PostgreSQL 落库、Excel 导出，以及 gRPC / MCP 双协议服务化输出。

生产效果

准确率分两种口径：按字段计算时，每个科目单独作为一个字段统计；按表计算时，要求整张表所有字段都正确才算通过。

统一抽象输入

PDF / 图片 / Excel 统一进入核心入口，后续映射、校验、导出都复用同一套能力。

分页检测 + 并发停止

PDF 逐页转图，并发判断是否为三表页，目标表找齐后提前停止，降低模型调用。

图像增强

基于 OpenCV 做去水印 / 去印章，ONNX 方向分类识别 0/90/180/270 自动旋转。

双通路抽取

优先走 OCR 控制成本，结构异常时自动回退 VL 大模型，平衡速度和成功率。

结构理解与主体识别

识别表头行、项目列、金额列和日期列，并融合多路信息识别公司主体。

规则化映射

通过 YAML 规则、别名匹配、高阈值模糊匹配和优先取值，把企业自定义字段统一到标准编码。

可用性校验

不仅校验资产=负债+权益，还区分空值/未识别，兼容新旧准则并定位失败项。

输出层工程化

gRPC 保留历史字段兼容；MCP 拆成 parse / map / inspect / markdown_to_excel 工具；支持落库导出。

关键难点

  • 不同企业、不同行业、不同年度的报表模板差异很大，表头命名、字段口径、排版方式并不统一。
  • 跨页长表仍是当前薄弱点：目前主要支持“资产负债表”“资产负债表（续）”这类显式续表，对中间无明确表头的 3-4 页长表还缺少稳定拼接。
  • 财务场景对准确性要求高，必须同时满足标准口径统一和财务逻辑自洽。
